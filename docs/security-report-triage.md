# Security report triage

The attached release audit was compared with the current source tree and the reported kernel-side blockers were rechecked after the latest implementation pass.

| Finding | Current source status | Final disposition |
|---|---|---|
| Makefile `PROJECT` missing | **Resolved**: `PROJECT ?= npkernel` is defined, an empty override is rejected, and kernel/ISO artefact names derive from the same variable. The default value matches `limine.conf`’s `boot():/boot/npkernel.elf` path. | Retained as a release gate. |
| `execve` creates a new process | **Resolved**: `sys_execve()` stages a complete replacement address space and commits it to the existing process/thread only after staging succeeds. PID/TID, parent relation and non-`FD_CLOEXEC` descriptors remain; `FD_CLOEXEC` descriptors are closed at commit. | Retained as an in-place exec regression gate. |
| `brk` overlaps VMA and unsafe rollback | **Resolved**: the heap is represented by a reserved heap VMA, `brk` resize checks the shared VMA reservation layer, and page changes are transactional. User `mmap`/`munmap`/`mprotect` cannot split or remove the heap reservation. | Retained as a brk/mmap/COW regression gate. |
| wait4 wakeup delays reap | **Resolved**: wakeup records a status-copyout result and claimed child PID in the parent wait state; the resumed waiter consumes the result and reaps the claimed zombie. Failed status copyout leaves the zombie available for a later retry. | Retained as a fork/exit/wait lifecycle gate. |
| Static-only ELF / dynamic linker | **Partially resolved by bounded kernel handoff**: `PT_INTERP` and `PT_DYNAMIC` receive bounded metadata validation, the interpreter is mapped into the staged address space, and `AT_BASE`, `AT_ENTRY`, `AT_PHDR`, `AT_PHNUM` and `AT_PHENT` are supplied. `DT_NEEDED` graph traversal, symbol resolution, TLS image handling and relocations remain userspace `ld.so` responsibilities. | Dynamic ELF handoff is implemented; a complete in-kernel or complete Linux dynamic-runtime compatibility claim is not made. |
| Incomplete pthread/Rust thread semantics | **Partially resolved by bounded thread ABI**: TID/TGID, constrained `clone`, `set_tid_address`, clear-child-tid futex wake, group-wide exit and signal targeting are implemented. Robust-list, PI/requeue/bitset futexes, cancellation/join details and all clone flags remain unsupported. | Bounded thread-group support is released; complete pthread/Rust runtime compatibility is not claimed. |
| No SMP | **Partially resolved by bring-up**: Limine MP response discovery and AP startup are implemented and QEMU `-smp 2` reports two CPUs online. APs remain in a safe idle loop because per-CPU run queues, IPI/timer routing and migration are not yet enabled. | SMP bring-up is released; SMP scheduling is not claimed. |
| No `poll`/`epoll` | **Resolved as bounded readiness ABI**: `poll`, `ppoll` and level-triggered `epoll` cover regular files, pipes and TTY readiness, with bounded watches and refcount-safe close cleanup. | Retained as a bounded I/O readiness gate; `select`, blocking wait queues and edge-triggered epoll remain unsupported. |
| No persistent filesystem | **Resolved as bounded persistent storage**: ATA PIO write support and fixed-region NPKFS `/persist` metadata/data, create/read/write/truncate/append, close flush, `fsync`, `fdatasync`, `sync` and readback paths are implemented. Dual metadata slots, CRC32, generation and a prepare/clear transaction marker provide bounded metadata recovery. | Persistent storage is released with explicit limitations: no data journaling, data-block checksum, true power-loss crash consistency, persistent directory tree or fault-injection guarantee. The new directory hierarchy is limited to immutable initramfs VFS. |
| Realtime signal payloads missing | **Resolved as bounded queued payloads**: `rt_sigqueueinfo` and `rt_tgsigqueueinfo` safely copy bounded `siginfo_t` fields including `si_code`, `si_pid`, `si_uid` and `si_value`; `SA_SIGINFO` delivery and `-EAGAIN` queue overflow are implemented. | Retained as a bounded realtime-signal gate; sigwait, nested frames and complete Linux queue semantics remain unsupported. |
| ELF adversarial corpus not expanded | **Resolved**: reproducible 38-case generator and host validator harness cover truncated/header/version, overflow, alignment, overlap, W+X, noncanonical range/entry, huge memory, interpreter and dynamic metadata cases. | Retained as `make test-elf-corpus` regression gate. |
| Toolchain/QEMU not reproducible | **Resolved in this environment**: Clang, `ld.lld`, NASM, `xorriso` and QEMU are present; a fresh build and artefact checks were run. The initramfs helper derives the project root from its own location and receives the Makefile output target, so an extracted checkout is not tied to `/home/ubuntu/npkernel`. | Retained as a release gate; exact toolchain manifest and fresh BIOS/UEFI tests should remain part of CI. | 
| Kernel-only desktop foundations absent | **Partially resolved**: immutable file-backed mmap, bounded shared-memory object/descriptor transfer, single-owner GOP framebuffer lease with controlled mapping, structured keyboard input, PS/2 mouse events, bounded initramfs directories and PCI enumeration are implemented and smoke-tested. | No userspace service/compositor is included. USB HID, device namespace, sockets/eventfd, network/audio, persistent directory filesystem, DMA/IOMMU and per-CPU SMP scheduling remain explicit platform blockers. |

The original P0/P1 release blockers are addressed in the current source tree. The release now includes bounded dynamic-ELF handoff, bounded thread primitives, bounded readiness polling, immutable file-backed mmap, shared-memory IPC, safe display/input handoff, bounded initramfs directories, PCI/PS2 mouse foundations, bounded persistent storage with metadata recovery, realtime signal payload queues, SMP AP bring-up and a reproducible 38-case ELF corpus. The remaining items are explicit semantic limits rather than undocumented missing implementations.

Drivers unrelated to the implemented ATA path, broad NPOS-specific userspace and production-grade filesystem features remain outside this remediation scope.
